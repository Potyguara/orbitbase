Plataforma GNSS para geração de base virtual offline

Bases virtuais com precisão e agilidade

O OrbitBase é uma plataforma web voltada à geração de bases virtuais offline e exportação RINEX a partir de dados históricos de estações GNSS de referência, com foco em organização, automação e consistência técnica.

Benefícios

Uma camada técnica sobre dados históricos GNSS

O OrbitBase automatiza etapas operacionais normalmente manuais, facilitando a seleção de estações, a organização das sessões e a exportação em RINEX.

Seleção inteligente de estações

Busca automática de estações GNSS compatíveis com a janela temporal e a área de interesse.

Base virtual offline

Geração orientada por critérios técnicos a partir de dados históricos de referência.

Exportação RINEX

Disponibilização do arquivo final em formato compatível com rotinas técnicas e pós-processamento.

Painel de consumo

Controle de minutos gerados, exportações realizadas e histórico por conta e projeto.

Organização por projetos

Centralização das sessões em ambiente web com rastreabilidade e controle operacional.

Escalável

Estrutura pensada para evoluir para múltiplos usuários, planos, relatórios e API.

Como funciona

Fluxo simples para uma operação técnica complexa

1

Envie sua sessão

Informe as coordenadas do local, janela temporal e a área de interesse.

2

Selecione no mínimo 3 bases de referência no mapa

O OrbitBase identifica estações de referência compatíveis para compor a base virtual.

3

Geração da base virtual

O job é processado e os minutos válidos gerados são registrados no painel do usuário.

4

Exportação RINEX

Ao final, o usuário baixa o arquivo exportado e acompanha os dados da sessão.

FAQ

Perguntas frequentes

O OrbitBase faz pós-processamento completo?

O foco principal da plataforma é a geração de base virtual offline em formato compatível com fluxos técnicos de pós-processamento. O processamento final pode ser realizado em softwares compatíveis adotados pelo usuário.

O sistema usa RBMC-IP em tempo real?

Não. Nesta fase, a plataforma trabalha com dados históricos e não opera com RBMC-IP.

O arquivo exportado pode ser usado em outros fluxos técnicos?

Sim. A proposta do OrbitBase é fornecer arquivos organizados para integração com rotinas técnicas de pós-processamento GNSS, especialmente em levantamentos com rovers reais realizados em campo.

Como funciona a cobrança?

O OrbitBase poderá operar com três modalidades: uso gratuito limitado, contratação sob demanda por minuto efetivamente gerado e assinatura mensal para uso recorrente da geração de base virtual offline.
